
コメント付きの判定例
--------------------
以下は、先ほどの擬似コードに処理の意味が分かるコメントを付けた例。実際に実装する時も、各判定が何を除外しているか分かるよう、このようなコメントを残す。

// TYPE_FAN の扇形範囲内にプレイヤーがいるか調べる
bool IsPlayerInsideFan(const D3DXVECTOR3& targetPos,
                       float targetYaw,
                       const D3DXVECTOR3& playerPos,
                       float fanLength,
                       float fanAngleDegrees)
{
    // ターゲット中心からプレイヤーまでの水平距離をXZ平面で求める
    const float dx = playerPos.x - targetPos.x;
    const float dz = playerPos.z - targetPos.z;
    const float distanceSq = dx * dx + dz * dz;

    // 扇の長さを超えていれば、角度を調べず範囲外とする
    if (distanceSq > fanLength * fanLength)
    {
        return false;
    }

    // 中心と同じ位置なら方向が定義できないため、範囲内として扱う
    if (distanceSq < 0.000001f)
    {
        return true;
    }

    // 長さ判定を通過した後だけ平方根を計算する
    const float distance = sqrtf(distanceSq);

    // このゲームではターゲットの前方が -sin(yaw), -cos(yaw) になる
    const float forwardX = -sinf(targetYaw);
    const float forwardZ = -cosf(targetYaw);

    // 前方ベクトルとプレイヤー方向ベクトルの内積を求める
    const float dot = forwardX * dx + forwardZ * dz;

    // fanAngleDegrees は扇全体の角度なので、片側の角度にしてcosを求める
    const float cosHalfAngle = cosf(D3DXToRadian(fanAngleDegrees * 0.5f));

    // 内積が境界値以上なら、プレイヤーは扇の角度内にいる
    return dot >= distance * cosHalfAngle;
}

既存関数へ追加する場合のコメント例
----------------------------------
CollisionPlayer() の冒頭に TYPE_FAN の分岐を置く。扇形はプレイヤーを押し出す壁ではなく範囲判定なので、ここで結果を返して既存の矩形押し戻し処理へ進ませない。

// 扇形タイプは矩形ではなく、前方の扇形範囲で判定する
if (m_type == TYPE_FAN)
{
    // 描画範囲と同じ中心・向き・長さ・角度を使って判定する
    return IsPlayerInsideFan(m_pos, m_rot.y, playerPos,
                             fanLength, fanAngleDegrees);
}
